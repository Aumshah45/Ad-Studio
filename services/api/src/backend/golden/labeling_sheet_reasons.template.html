How to use this sheet (rubric version @@RUBRIC_VERSION@@)

These are the @@N@@ images you failed on product or context, with your current labels loaded. For every failed dimension, choose the reason (required) and add a note if useful. It does not show any evaluator output.

Choosing scale or pasted means the problem is really composition: the sheet sets that dimension to pass and composition to fail (highlighted in amber). If the dimension really fails as well, for example a product that is both oversized and recoloured, set it back to fail with its radio. Any other reason keeps the fail.

Download writes the full labels.csv (every other row unchanged, reasons in notes as reason:<dimension>=<code>). Save it as @@SAVE_AS@@.
